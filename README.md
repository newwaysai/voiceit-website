# VoiceIt Website

Marketing-Site für die VoiceIt macOS-App — [voiceitai.app](https://voiceitai.app).

## Quick Start

```bash
npm install
npm run dev
```

Öffne `http://localhost:3000`.

## Deploy

Push auf `main` → Vercel auto-deploy auf `voiceitai.app`.

## Stack

Next.js 16 · React 19 · Tailwind CSS 4 · GSAP · Vercel
